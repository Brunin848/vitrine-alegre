# 📝 Prompts Utilizados no Desenvolvimento

Este documento registra os principais comandos e orientações fornecidos à Inteligência Artificial durante a construção e depuração do projeto **Vitrine Alegre**.

---

## 📍 Prompt 1: Estruturação Inicial do Projeto
> "Crie a estrutura de um e-commerce simples em React utilizando React Router DOM para navegação. Preciso de páginas para a Home (vitrine de produtos), Detalhes do Produto (`/produto/:id`) e Carrinho (`/carrinho`). Use a Context API para gerenciar o estado global do carrinho."

---

## 📍 Prompt 2: Diagnóstico de Falha na Navegação
> "Gemini, não é o carrinho, ele abre normalmente, por favor NÃO altere nada do carrinho. O que não abre é o detalhe do produto, eu clico nele e nada acontece."

---

## 📍 Prompt 3: Solução de Conflito de Clique no Card
> "O botão de 'Adicionar ao Carrinho' que fica no card do produto na Home está disparando a navegação para a tela de detalhes ou não abre a página. Como posso corrigir para que o clique na imagem/título abra os detalhes e o clique no botão apenas adicione ao carrinho?"

---

## 📍 Prompt 4: Resolução de Erros de Git e Envios ao Repositório
> "Recebi o erro `fatal: unable to auto-detect email address` no Git e em seguida `error: src refspec main does not match any` ao tentar executar `git push -u origin main --force`. Como configuro minhas credenciais e forço a atualização no repositório existente sem perder os arquivos novos?"

---

## 📍 Prompt 5: Documentação do Projeto
> "Crie um README.md que leva qualquer pessoa do zero ao app rodando, um PROMPTS.md com as conversas que produziram o código e um DIARIO-DA-IA.md com pelo menos cinco erros que a IA cometeu, como percebi e como corrigi."
